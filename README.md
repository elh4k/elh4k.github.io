# elh4k — tim sa ELFAK-a

Statični portfolio sajt tima **elh4k** (studenti Elektronskog fakulteta u Nišu) za **Novium Hakaton 2026**.

## Lokalni pregled

Sajt nema build korak, JavaScript niti spoljne zavisnosti. Može se otvoriti direktno sa diska (`index.html`) ili pokrenuti lokalnim HTTP serverom:

```bash
python3 -m http.server 8000
```

Zatim otvorite `http://localhost:8000` u pregledaču.

## GitHub Pages deploy

- **Organizacija:** `elh4k`
- **Repozitorijum:** `elh4k.github.io`
- **Grana:** `main` (root `/`)
- **URL:** `https://elh4k.github.io/`

## Ažuriranje sadržaja

Izmenite podatke u `index.html` (i prateće avatare u `assets/avatars/`), vodeći računa da sve putanje ostanu relativne (`./...`).

## Fotografije i privatnost

- Fotografije članova tima u `assets/avatars/` preuzete su sa javnih LinkedIn profila i koriste se uz saglasnost članova tima.
- Na sajtu se ne objavljuju nikakve email adrese, brojevi telefona niti drugi privatni podaci.
