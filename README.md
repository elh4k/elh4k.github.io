# elh4k · tim sa ELFAK-a

Statični portfolio sajt tima **elh4k** (studenti Elektronskog fakulteta u Nišu) za **Novium Hakaton 2026**.

## Lokalni pregled

Sajt koristi HTML, CSS i JavaScript (`script.js`) bez spoljnih biblioteka, zavisnosti i build koraka. Otvorite `index.html` direktno sa diska ili pokrenite lokalni HTTP server.

```bash
python3 -m http.server 8000
```

Zatim otvorite `http://localhost:8000` u pregledaču.

## GitHub Pages deploy

- **Organizacija:** `elh4k`
- **Repozitorijum:** `elh4k.github.io`
- **Grana:** `main` (root `/`)
- **URL:** `https://elh4k.github.io/`

## Ažuriranje sadržaja

Izmenite podatke u `index.html` (i prateće avatare u `assets/avatars/`), vodeći računa da sve putanje ostanu relativne (`./...`). Prošireni profili mogu se otvoriti u samoj kartici kada je JavaScript isključen.

## Fotografije i privatnost

- Fotografije Jane, Lazara i Nikole preuzete su sa javnih LinkedIn profila i koriste se uz saglasnost članova tima. Fotografije Bogdana i Dimitrija dodate su iz priloženih fajlova.
- Na sajtu se ne objavljuju nikakve email adrese, brojevi telefona niti drugi privatni podaci.
